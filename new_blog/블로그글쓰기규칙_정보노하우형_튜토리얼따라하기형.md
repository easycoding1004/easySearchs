# 정보·노하우형 — 튜토리얼·따라하기형

> "OO 하는 법", "OO 설치 방법"처럼 단계별로 따라 하면 결과가 나오는 글. 프로그램 설치, 코딩 실습, 신청 절차 안내 등이 여기 해당돼요.

## 제목 규칙
- 핵심 키워드를 앞부분에, 25자 내외
- "~하는 법 / ~설치 방법 / ~따라하기 / ~단계별 정리" 등 절차 검색 의도가 뚜렷한 표현 사용

## 글 구조
| 구간 | 내용 | 분량 |
|---|---|---|
| 서론 | 무엇을 완성하게 될지, 준비물(있다면) | 2~3문장 |
| 본론 | 번호 목록(`1. `)으로 단계별 정리 — 단계마다 스크린샷/사진 1장씩 | 단계당 2~4문장 |
| 결론 | 완성 확인 방법 + 자주 막히는 지점 팁 | 2~3문장 |

- 단계는 실제로 실행 가능한 순서 그대로, 건너뛰지 않기
- 막히기 쉬운 단계는 "이 부분에서 대부분 헷갈려요" 식으로 미리 짚어주면 신뢰도가 올라감

## 이미지/영상 배치 (권장 4~8장, SLOT / 영상 0~1)
단계별로 정확한 위치가 중요하므로 SLOT을 씁니다 — 각 단계 바로 아래에 그 단계의 스크린샷을 배치.

```
[[SLOT: 이미지 | 개수=5 | 역할=1단계,2단계,3단계,4단계,완성화면 | 사진=1,2,3,4,5 | 힌트="각 단계 화면 캡처"]]
[[SLOT: 영상 | 개수=1 | 역할=전체과정영상 | 힌트="처음부터 끝까지 진행 화면"]]
```

## 특징 마크업
- 번호 목록(`1. `, `2. `, ...)을 단계 설명에 반드시 사용
- 완성 결과물은 `[[QUOTE: "..."]]`로 강조 가능

## 발행 전 체크리스트
- [ ] 단계가 실제 실행 순서와 정확히 일치하는가
- [ ] 각 단계마다 확인할 화면/결과가 명시됐는가
- [ ] 자주 막히는 지점에 대한 팁이 있는가
