# 홍보·광고형 — 커리큘럼 소개형

> 학원·수업의 커리큘럼을 자세히 소개하는 글. 신규 모집 안내형과 비슷하지만 이 유형은 "가입 유도"보다 **커리큘럼 자체의 정보성**이 중심이에요.

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 이 커리큘럼이 어떤 고민을 해결해주는지 |
| 본론 | 단계별/레벨별 커리큘럼 구성을 표로 정리 + 각 단계 상세 설명 |
| 결론 | 자연스러운 CTA 1개 |

## 이미지/영상 배치 (권장 4~8장, 영상 0~1)
```
[[SLOT: 이미지 | 개수=4 | 역할=커리큘럼표,수업자료1,수업자료2,결과물예시 | 사진=1,2,3,4 | 힌트="..."]]
```

## 특징 마크업
- **TABLE이 이 유형의 핵심** — 단계별 커리큘럼을 표로:
```
[[TABLE: 헤더="단계,기간,내용" | 행1="입문,4주,..." | 행2="심화,8주,..."]]
```
- 마지막에 `[[LINK: url="..." | 설명="상담 신청하기"]]` CTA 1개

## 발행 전 체크리스트
- [ ] 커리큘럼이 표로 한눈에 정리됐는가
- [ ] 단계별 상세 설명이 표와 중복되지 않고 보완하는가
- [ ] CTA가 1개, 마지막에만 있는가
