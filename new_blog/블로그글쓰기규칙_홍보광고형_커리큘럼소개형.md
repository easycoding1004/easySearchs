# 홍보·광고형 — 상품·서비스 소개형

> 판매하는 상품 라인업이나 제공하는 서비스 구성을 자세히 소개하는 글. 신규 고객·회원 모집형과 비슷하지만 이 유형은 "가입 유도"보다 **구성 자체의 정보성**이 중심이에요.

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 이 상품·서비스 구성이 어떤 고민을 해결해주는지 |
| 본론 | 단계별/종류별 구성을 표로 정리 + 각 구성 상세 설명 |
| 결론 | 자연스러운 CTA 1개 |

## 이미지/영상 배치 (권장 4~8장, 영상 0~1)
```
[[SLOT: 이미지 | 개수=4 | 역할=구성표,자료1,자료2,결과물예시 | 사진=1,2,3,4 | 힌트="..."]]
```

## 특징 마크업
- **TABLE이 이 유형의 핵심** — 종류별 구성을 표로:
```
[[TABLE: 헤더="구성,내용,가격" | 행1="베이직,...,..." | 행2="프리미엄,...,..."]]
```
- 마지막에 `[[LINK: url="..." | 설명="상담 신청하기"]]` CTA 1개

## 발행 전 체크리스트
- [ ] 구성이 표로 한눈에 정리됐는가
- [ ] 구성별 상세 설명이 표와 중복되지 않고 보완하는가
- [ ] CTA가 1개, 마지막에만 있는가
