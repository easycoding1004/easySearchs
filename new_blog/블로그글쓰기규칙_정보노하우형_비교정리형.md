# 정보·노하우형 — 비교·정리형

> "OO vs OO", "OO 총정리"처럼 여러 선택지·정보를 한눈에 비교하거나 정리해주는 글. "온라인 vs 오프라인 수업", "전형별 총정리" 등이 여기 해당돼요.

## 제목 규칙
- 핵심 키워드를 앞부분에, 25자 내외
- "~비교 / ~차이 / ~총정리 / ~한눈에 보기" 등 정리 검색 의도가 뚜렷한 표현 사용

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 무엇과 무엇을 비교하는지, 왜 헷갈리는지 (두괄식) |
| 본론 | 비교 기준을 먼저 제시 → 표로 한눈에 정리 → 기준별 자세한 설명 |
| 결론 | "이런 사람에게는 A, 저런 사람에게는 B"처럼 상황별 결론 |

- 정답을 하나로 단정하기보다, 독자 상황에 따라 다른 결론을 제시하면 신뢰도가 올라감

## 이미지/영상 배치 (권장 2~4장)
소량이라 SLOT으로 정밀 배치합니다.

```
[[SLOT: 이미지 | 개수=2 | 역할=A항목예시,B항목예시 | 사진=1,2 | 힌트="..."]]
```

## 특징 마크업
- **TABLE이 이 유형의 핵심** — 비교 기준을 표로 반드시 정리:
```
[[TABLE: 헤더="항목,A,B" | 행1="가격,...,..." | 행2="장점,...,..." | 행3="단점,...,..."]]
```
- 표 위/아래에 `[[QUOTE: "..."]]`로 핵심 결론을 한 문장으로 강조하면 좋음

## 발행 전 체크리스트
- [ ] 비교 기준이 명확한가(가격/장점/단점 등)
- [ ] TABLE 블록으로 한눈에 정리했는가
- [ ] 상황별 결론(정답 단정 아님)을 제시했는가
