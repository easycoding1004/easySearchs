# AI 초안 블록 구조 — 확장판

이전 버전(4유형 / 이미지 최대 6장 / 슬롯 2종)을 아래처럼 확장했습니다.

- 유형: 4개 대분류 → 16개 소분류로 세분화
- 이미지: 슬롯당 최대 50장까지 가능한 GALLERY 문법 추가
- 마크업: 인용구·구분선·표·장소·링크 블록 추가

`[[ ]]` 표기는 저희 쪽에서 정의한 중간 표현이에요. 실제 삽입 시에는 이걸 에디터가 진짜로 지원하는 기능(사진, 동영상, 지도, 인용구 등)으로 변환해서 넣는 방식입니다.

---

## 1. 16개 유형 분류

| 대분류 | 소분류 | 이미지 권장 | 영상 | 특징 마크업 |
|---|---|---|---|---|
| 정보·노하우형 | 개념 설명형 | 2~4장 | - | QUOTE, DIVIDER |
| 정보·노하우형 | 튜토리얼·따라하기형 | 4~8장 (SLOT) | 0~1 | 번호 리스트 |
| 정보·노하우형 | 비교·정리형 | 2~4장 | - | TABLE |
| 정보·노하우형 | Q&A·FAQ형 | 1~3장 | - | QUOTE(질문 강조) |
| 리뷰·후기형 | 수업·특강 후기형 | 8~15장 | 1 | GALLERY |
| 리뷰·후기형 | 학생 성과·발표 후기형 | 6~12장 | 1~2 | GALLERY, QUOTE |
| 리뷰·후기형 | 교재·도구 리뷰형 | 4~8장 | 0~1 | TABLE(스펙 비교) |
| 리뷰·후기형 | 비교 후기형 | 4~6장 | - | TABLE |

| 홍보·광고형 | 행사·설명회 안내형 | 5~15장 (GALLERY 가능) | 1 | PLACE, LINK, GALLERY |

## 2. 확장된 문법

### 2-1. 기존 SLOT — 정밀 배치용 (소량, 역할 지정)

사진 한 장 한 장의 역할이 중요할 때만 씁니다. 최대 8장 정도까지 권장.

```
[[SLOT: 이미지 | 개수=3 | 역할=대표사진,과정컷,후기컷 | 힌트="..."]]
```

### 2-2. 신규 GALLERY — 대량 배치용 (최대 50장)

역할을 하나하나 지정하기 힘든 대량의 사진(브이로그, 행사 스냅 등)에 사용합니다.

```
[[GALLERY: 이미지 | 개수=35 | 배치=그리드 | 힌트="이날 하루 수업 스냅 전체, 순서 무관"]]
```

`배치` 옵션: 그리드(격자 나열) / 슬라이드(가로 스크롤) / 콜라주(자동 배치)

한 글 안에 SLOT과 GALLERY를 같이 써도 됩니다 — 대표사진 몇 장은 SLOT으로 정확히 지정하고, 나머지는 GALLERY로 뭉치 배치하는 식으로요.

### 2-3. 신규 마크업 블록

- 인용구 : `[[QUOTE: "강조하고 싶은 한 문장"]]`
- 구분선 : `[[DIVIDER]]`
- 표 : `[[TABLE: 헤더="A,B,C" | 행1="1,2,3" | 행2="4,5,6"]]`
- 장소·지도 : `[[PLACE: 이름="OO코딩학원" | 힌트="네이버 지도 자동 연동"]]`
- 링크 카드 : `[[LINK: url="https://..." | 설명="신청 페이지로 이동"]]`

### 2-4. 이미지 배치 스타일

SLOT·GALLERY 모두 `배치=` 옵션으로 시각 스타일 지정 가능: 1단(세로 나열) / 2단(좌우 배치) / 콜라주(자동 격자) / 와이드(가로로 꽉 차게)

## 3. 예시

### 예시 A. 수업 브이로그형 (일상·에세이) — 대량 이미지 데모

```
---
글유형: 수업 브이로그형
제목: 코딩 캠프 3일차, 이렇게 하루를 보냈어요
예상 슬롯: 이미지 38개(SLOT 3 + GALLERY 35), 영상 1개
---

## 오늘 하루를 소개할게요

3일차는 미니 프로젝트 발표를 준비하는 날이었어요.

[[SLOT: 이미지 | 개수=1 | 역할=대표사진 | 힌트="아침 등원 장면, 밝은 분위기"]]

## 하루 스냅 모음

[[GALLERY: 이미지 | 개수=35 | 배치=그리드 | 힌트="오전~오후 수업 스냅 전체, 순서 무관"]]

## 마무리 발표

[[SLOT: 이미지 | 개수=2 | 역할=발표컷 | 힌트="발표 시작 장면, 박수받는 장면"]]
[[SLOT: 영상 | 개수=1 | 역할=발표영상 | 힌트="대표 발표 20초"]]
```

→ 정확히 자리를 잡아야 하는 사진은 SLOT, 나머지 다수는 GALLERY로 한 번에 처리합니다.

### 예시 B. 비교·정리형 (정보·노하우) — 마크업 다양성 데모

```
---
글유형: 비교·정리형
제목: 온라인 코딩수업 vs 오프라인 학원, 우리 아이한텐 뭐가 맞을까
예상 슬롯: 이미지 2개, 영상 0개, 표 1개
---

## 무엇이 다를까요

[[QUOTE: "정답은 없어요, 아이의 성향에 달려 있습니다"]]

[[DIVIDER]]

## 한눈에 비교하기

[[TABLE: 헤더="항목,온라인,오프라인" | 행1="집중도,보호자 관리 필요,자연스럽게 유지" | 행2="또래 교류,어려움,활발함" | 행3="이동 부담,없음,있음"]]

[[SLOT: 이미지 | 개수=2 | 역할=비교컷 | 힌트="온라인 수업 화면, 오프라인 수업 장면"]]

## 그래서 우리 학원은

두 방식의 장점을 섞어서, 주 1회는 대면·나머지는 온라인 보충으로 운영하고 있어요.
```

→ 표(TABLE)·인용구(QUOTE)·구분선(DIVIDER)을 섞어서 정보를 정돈된 형태로 보여줍니다.

### 예시 C. 행사·설명회 안내형 (홍보·광고) — 장소·링크 데모

```
---
글유형: 행사·설명회 안내형
제목: 2026 겨울방학 설명회, 학부모님을 초대합니다
예상 슬롯: 이미지 12개(SLOT 2 + GALLERY 10), 장소 1개, 링크 1개
---

## 설명회에 초대합니다

겨울방학 특강 커리큘럼을 직접 설명드리는 자리를 마련했습니다.

[[SLOT: 이미지 | 개수=1 | 역할=대표사진 | 힌트="설명회 포스터"]]

[[PLACE: 이름="OO코딩학원 3층 세미나실" | 힌트="네이버 지도 자동 연동"]]

## 지난 설명회 현장

[[GALLERY: 이미지 | 개수=10 | 배치=콜라주 | 힌트="이전 설명회 스냅 10장"]]

## 참석 신청

[[LINK: url="https://ezzsearch.com/event" | 설명="선착순 마감, 지금 바로 신청하기"]]
```

→ 장소(PLACE)와 링크(LINK)가 들어가면서 "찾아오고, 신청까지 이어지는" 홍보형 글의 흐름이 완성됩니다.

---

## 4. 정리

- 유형 : 4대분류 → 16소분류로 세분화 (1번 표 참고)
- 이미지 : SLOT(정밀·소량) + GALLERY(대량·최대 50장) 두 트랙으로 운영
- 마크업 : 인용구·구분선·표·장소·링크 5종 추가, 배치 스타일 4종 선택 가능

표에 있는 숫자·구성은 전부 유형별 기본값일 뿐이에요. 팝업 UI에서 유형을 고르면 이 기본값이 자동으로 채워지고, +/- 버튼이나 블록 추가로 그때그때 바로 조절하는 구조는 이전 버전과 동일하게 유지됩니다.
