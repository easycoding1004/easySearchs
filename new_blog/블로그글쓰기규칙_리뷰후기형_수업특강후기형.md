# 리뷰·후기형 — 수업·특강 후기형

> 진행한 수업이나 특강이 어땠는지 소개하는 글. 협찬 여부는 이 유형과 별개(사용자가 별도 토글로 지정 — `블로그글쓰기규칙_협찬표기.md` 참고).

## 제목 규칙
- 수업명·주제 + 핵심 키워드 조합 (예: "여름방학 코딩특강 후기")

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 어떤 수업이었는지, 몇 명이 참여했는지 |
| 본론 | ① 수업 내용 소개 ② 진행 분위기·학생 반응 ③ 이 수업만의 특징 ④ 아쉬웠던 점(있다면) |
| 결론 | 다음 수업 예고 또는 이런 학생에게 추천 |

- 장점만 나열하지 말고, 개선하고 싶은 점도 솔직하게 한 가지 정도 남기면 진정성이 올라감

## 이미지/영상 배치 (권장 8~15장, 영상 1개)
현장감이 중요한 유형이라 GALLERY 위주로 다량 배치합니다.

```
[[SLOT: 이미지 | 개수=2 | 역할=대표사진,수업준비물 | 사진=1,2 | 힌트="..."]]
[[GALLERY: 이미지 | 개수=10 | 배치=그리드 | 사진=3-12 | 힌트="수업 진행 전체 스냅"]]
[[SLOT: 영상 | 개수=1 | 역할=수업하이라이트 | 힌트="가장 재밌었던 순간 15~30초"]]
```

## 발행 전 체크리스트
- [ ] 수업 내용이 구체적으로 드러나는가
- [ ] 아쉬운 점도 최소 1가지 포함했는가(솔직함)
- [ ] GALLERY 사진 개수가 실제 업로드 사진 개수를 넘지 않는가
