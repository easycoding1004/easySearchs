# 리뷰·후기형 — 제품·도구 리뷰형

> 업무·매장 운영에 쓰는 제품·프로그램·도구를 소개·평가하는 글. 협찬 여부는 이 유형과 별개(사용자가 별도 토글로 지정).

## 제목 규칙
- 제품명 + 핵심 키워드 조합 (예: "매장용 커피머신 3개월 사용 후기")

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 이 제품·도구를 왜 쓰게 됐는지 |
| 본론 | ① 상세 소개(구성·스펙) ② 실제 사용 경험 ③ 장점 ④ 단점·아쉬운 점(반드시 포함) ⑤ (가능하면) 다른 제품과 비교 |
| 결론 | 총평 + 이런 상황에 추천 |

- 단점을 최소 1가지 이상 포함해야 신뢰도가 올라감(협찬이면 필수, 아니어도 권장)

## 이미지/영상 배치 (권장 4~8장, 영상 0~1)
```
[[SLOT: 이미지 | 개수=4 | 역할=외관구성,사용장면,디테일,비교컷 | 사진=1,2,3,4 | 힌트="..."]]
```

## 특징 마크업
- 다른 제품과 비교한다면 `[[TABLE: 헤더="항목,이 제품,다른 제품" | ...]]`로 정리하면 좋음

## 발행 전 체크리스트
- [ ] 장점만 나열하지 않고 단점도 포함했는가
- [ ] 직접 사용해본 구체적 경험이 드러나는가
- [ ] 사진이 실제 사용 장면 위주인가
