# 네이버 블로그 유형별 글쓰기 규칙 — 개요

목적·성격 기준으로 블로그 글을 4가지 유형으로 나누고, 유형별 구조·이미지 배치·노출 규칙을 정리했습니다.

## 먼저 짚고 갈 것 — "조회수 크롤링"의 한계
네이버 블로그는 개별 글의 조회수를 작성자 본인에게만 공개합니다. 외부에서 "조회수가 가장 높은 글"을 걸러내는 것은 불가능합니다(블로그 지수 외부 조회가 막힌 것과 같은 맥락). 그래서 아래 문서들은 다음 두 가지를 근거로 작성했습니다.

1. **노출(검색 상위 랭킹)** — 특정 키워드로 검색했을 때 실제로 상위에 뜨는 글의 패턴. 이건 공개된 정보라 확인 가능합니다.
2. **SEO·블로그 마케팅 전문가들의 분석** — 다수의 고성과 글을 분석해서 정리한 구조·이미지 공식, 그리고 2026년 기준 네이버 C-Rank·D.I.A 알고리즘 가이드

## 참고 — 네이버 검색 노출 알고리즘 (모든 유형 공통)
- **C-Rank**: 블로그(출처) 단위 평가. 한 주제를 얼마나 꾸준하고 신뢰 있게 다루는지(주제 집중도·콘텐츠 품질·반응)를 봄
- **D.I.A(+)**: 글 단위 평가. 검색 의도에 맞는 정보를 담고 있는지, 글자 수보다 정보 밀도·유용성을 봄
- 과거의 "이미지 다다익선, 글자수 억지로 늘리기" 공식은 최근 알고리즘에서는 효과가 줄었고, 지금은 **질(연관성·해결력)이 양보다 우선**이라는 것이 2026년 기준 공통된 분석입니다.

## 유형 간 공통 규칙
- 제목: 핵심 키워드를 앞부분에, 25자 내외
- 본문: 최소 1,500자 이상 — 단, 정보 밀도가 우선이지 억지로 채우는 게 아님
- 이미지: 직접 촬영·원본 위주, 재사용 시 편집 필수
- 협찬·광고·제휴마케팅이 조금이라도 섞였다면 `리뷰후기형_협찬체험단.md` / `홍보광고형.md` 문서의 공정위 표기 규정을 반드시 확인
