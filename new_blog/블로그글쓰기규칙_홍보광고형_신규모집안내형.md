# 홍보·광고형 — 신규 모집 안내형

> 신규 수강생·회원을 모집하는 글. 협찬 여부는 이 유형과 별개(광고성 글이라도 "협찬"과는 다른 개념 — 사용자가 직접 운영하는 곳을 알리는 글이면 협찬 토글은 꺼둠).

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 타깃 독자가 공감할 만한 고민으로 시작 (예: "코딩을 처음 시작하는 우리 아이, 어디서부터 시작해야 할지 모르겠다면") |
| 본론 | 모집 대상, 커리큘럼 특징, 이걸 들으면 뭐가 달라지는지(혜택 중심) |
| 결론 | 자연스러운 CTA(신청 방법) 1개 |

- 특징을 나열하기보다 "이걸 들으면 무엇이 달라지는지"로 풀어야 전환이 잘 됨
- CTA는 마지막에 1개만, 본문 중간에 반복하지 않기 — 네이버 블로그는 CTA·외부 링크 남발 시 저품질로 분류될 위험이 있음

## 이미지/영상 배치 (권장 3~6장, 영상 1개)
```
[[SLOT: 이미지 | 개수=3 | 역할=수업환경,커리큘럼자료,학생모습 | 사진=1,2,3 | 힌트="..."]]
[[SLOT: 영상 | 개수=1 | 역할=소개영상 | 힌트="학원 소개 30초"]]
```

## 특징 마크업
- `[[PLACE: 이름="OO학원" | 힌트="네이버 지도 자동 연동"]]`으로 위치 안내
- `[[LINK: url="..." | 설명="신청 페이지로 이동"]]`으로 CTA 링크(마지막에 1개만)

## 발행 전 체크리스트
- [ ] 특징 나열이 아니라 "무엇이 좋아지는지"로 풀었는가
- [ ] CTA가 1개, 마지막에만 있는가
- [ ] PLACE·LINK 정보가 정확한가
