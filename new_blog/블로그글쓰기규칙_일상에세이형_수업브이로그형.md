# 일상·에세이형 — 수업 브이로그형

> 하루 수업 전체를 사진/영상 위주로 기록하는 글. 이 유형이 **이미지 개수가 가장 많은 유형**이에요(대량 GALLERY 활용).

## 글의 성격
- 텍스트보다 사진·영상이 주인공 — 글은 짧고 자연스러운 설명 정도면 충분
- 하루의 흐름을 시간순으로 따라가는 구성이 자연스러움

## 글 구조
- 도입: 오늘이 어떤 날이었는지 한두 문장
- 전개: 시간 흐름대로 소제목을 나눠(예: "## 오전 수업", "## 점심시간", "## 오후 발표") 각 구간마다 짧은 설명 + 사진
- 마무리: 오늘 하루 소감 한두 문장

## 이미지/영상 배치 (권장 20~50장, 영상 0~1) — GALLERY 중심
정확한 자리가 중요한 몇 장만 SLOT, 나머지 다수는 GALLERY로 뭉치 배치합니다.

```
[[SLOT: 이미지 | 개수=1 | 역할=대표사진 | 사진=1 | 힌트="아침 등원 장면, 밝은 분위기"]]

[[GALLERY: 이미지 | 개수=35 | 배치=그리드 | 사진=2-36 | 힌트="오전~오후 수업 스냅 전체, 순서 무관"]]

[[SLOT: 영상 | 개수=1 | 역할=하이라이트영상 | 힌트="가장 기억에 남는 순간 15~30초"]]
```

## 발행 전 체크리스트
- [ ] 시간 흐름대로 구성됐는가
- [ ] GALLERY 사진 개수가 실제 업로드 사진 개수를 넘지 않는가
- [ ] 텍스트가 사진을 방해하지 않을 정도로 간결한가
