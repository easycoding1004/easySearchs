# 정보·노하우형 — Q&A·FAQ형

> 자주 묻는 질문을 모아 답하는 글. "손님들이 가장 많이 묻는 질문 5가지" 같은 형태예요.

## 제목 규칙
- 핵심 키워드를 앞부분에, 25자 내외
- "~자주 묻는 질문 / ~궁금한 점 총정리 / FAQ" 등의 표현 사용

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 어떤 대상이 자주 묻는 질문을 모았는지 (예: "상담하며 가장 많이 받는 질문 5가지") |
| 본론 | Q&A 반복 — 질문마다 소제목(`## Q1. ...`)으로 구분, 답변은 두괄식 |
| 결론 | 추가 질문은 어떻게 하면 되는지(상담 방법 등) |

- 질문은 실제로 자주 들어오는 것 위주로, 너무 뻔한 질문만 나열하지 않기
- 답변은 짧고 명확하게 — 장황한 설명보다 핵심부터

## 이미지/영상 배치 (권장 1~3장)
질문마다 이미지가 필요한 건 아님 — 꼭 필요한 곳에만 SLOT으로.

```
[[SLOT: 이미지 | 개수=1 | 역할=관련화면 | 사진=1 | 힌트="..."]]
```

## 특징 마크업
- 각 질문을 `[[QUOTE: "Q. 질문 내용"]]`으로 강조해서 답변과 시각적으로 구분하면 가독성이 좋아짐

## 발행 전 체크리스트
- [ ] 질문이 실제로 자주 나오는 것인가
- [ ] 답변이 두괄식으로 핵심부터 나오는가
- [ ] 질문과 답변이 시각적으로 구분되는가(QUOTE 등)
