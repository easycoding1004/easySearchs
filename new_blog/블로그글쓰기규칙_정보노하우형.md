# 정보·노하우형 블로그 글쓰기 규칙

> "OO 하는 법", "OO 정리", "OO 해결 방법"처럼 지식 전달·문제 해결이 목적인 글. 특성화고 학과 안내, 코딩 개념 설명, 입시 정보 정리 등이 대부분 이 유형에 해당돼요.

## 1. 제목 규칙
- 핵심 키워드를 제목 **앞부분**에 배치 (뒤로 갈수록 검색 가중치가 낮아짐)
- 전체 제목은 25자 내외
- "~하는 법 / ~정리 / ~총정리 / ~완벽 가이드 / ~꿀팁" 등 검색 의도가 뚜렷한 표현 사용

## 2. 글 구조

| 구간 | 내용 | 분량 |
|---|---|---|
| 서론 | 문제 상황 제기 → 이 글이 무엇을 해결해줄지 예고 (두괄식) | 2~4문장 |
| 본론 | 소제목 3~5개로 나눠 단계별·항목별로 정리 | 소제목당 2~4문장 + 리스트 |
| 결론 | 핵심 요약 + 추가 팁 또는 자주 묻는 질문 | 2~3문장 |

- 두괄식으로 쓰기: 가장 중요한 결론·답을 먼저 제시하고 부연설명은 뒤로
- 문단을 짧게 끊고 리스트·번호를 적극 활용해서, 훑어봐도 핵심이 보이게 구성

## 3. 이미지 배치
- 소제목(문단) 하나당 이미지 1장이 기준
- 텍스트로 설명하기 어려운 절차·화면은 스크린샷이나 직접 촬영 이미지로 보완
- 재사용 이미지는 그대로 쓰지 말고 크기·파일명 등을 편집해서 사용 (원본 여부를 알고리즘이 인식함)
- 과거에는 "이미지 많을수록 유리"하다는 공식이 통했지만, 최근에는 양보다 **내용과의 연관성**이 더 중요해졌으므로 억지로 채우지 않기

## 4. 노출(SEO) 체크포인트
- [ ] 본문 글자 수 최소 1,500자 이상 (억지로 늘리지 않고 정보 밀도를 우선)
- [ ] 핵심 키워드를 본문에 3~5회 자연스럽게 반복 + 유사·연관 키워드 함께 사용
- [ ] 목차(TOC)를 넣어서 독자가 원하는 정보로 바로 이동할 수 있게 하기
- [ ] 타깃 키워드는 월간 검색량 500~5,000 수준이 노출 난이도 대비 유입 밸런스가 좋다는 의견이 많음
- [ ] 발행 후 네이버 서치어드바이저에 색인 요청

## 5. 발행 전 체크리스트
- [ ] 제목에 핵심 키워드 포함 + 25자 이내
- [ ] 서론이 두괄식인가
- [ ] 소제목 3~5개 구조를 갖췄는가
- [ ] 소제목당 이미지 1장 내외
- [ ] 결론에 요약이 들어갔는가
- [ ] 학과명·전형명·수치 등 고유명사·숫자를 다시 한 번 확인했는가
