# 정보·노하우형 — 개념 설명형

> "OO이란", "OO 원리", "OO 차이점"처럼 어떤 개념·용어·원리를 쉽게 풀어 설명하는 글. 코딩 용어, 입시 제도, 학과 개념 설명 등이 여기 해당돼요.

## 제목 규칙
- 핵심 키워드를 앞부분에, 25자 내외
- "~이란 / ~뜻 / ~원리 / ~차이" 등 개념 검색 의도가 뚜렷한 표현 사용

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 이 개념을 왜 알아야 하는지, 흔히 헷갈리는 부분 예고 (두괄식) |
| 본론 | 소제목 2~4개로 정의 → 왜 그런지(원리) → 실제 예시 순서로 전개 |
| 결론 | 한 문장 요약 + 관련해서 더 알면 좋을 것 |

- 두괄식으로 쓰기: 정의부터 먼저 제시하고 부연설명은 뒤로
- 비유나 실생활 예시를 하나 이상 넣으면 이해도가 크게 올라감

## 이미지/영상 배치 (권장 2~4장)
소량이라 SLOT으로 정밀 배치합니다.

```
[[SLOT: 이미지 | 개수=3 | 역할=개념도해,예시화면,결과화면 | 사진=1,2,3 | 힌트="..."]]
```

## 특징 마크업
- `[[QUOTE: "..."]]`로 핵심 정의를 한 번 더 강조하면 좋음
- `[[DIVIDER]]`로 "정의 → 원리 → 예시" 구간을 시각적으로 구분 가능

## 발행 전 체크리스트
- [ ] 정의를 서론에서 먼저 제시했는가(두괄식)
- [ ] 비유·실생활 예시가 최소 1개 있는가
- [ ] 전문 용어를 쓸 때 바로 뒤에 쉬운 설명을 덧붙였는가
