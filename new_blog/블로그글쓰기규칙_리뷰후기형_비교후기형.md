# 리뷰·후기형 — 비교 후기형

> 두 가지 이상의 선택지를 실제 경험 기준으로 비교하는 후기. "온라인 수강 vs 오프라인 수강, 둘 다 해본 후기" 같은 형태예요.

## 제목 규칙
- "A vs B" 또는 "A, B 둘 다 해본 후기" 형태 + 핵심 키워드

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 왜 둘 다(또는 여러 개) 경험하게 됐는지 |
| 본론 | 기준별로 A/B를 각각 경험한 내용 비교 (가격, 만족도, 장단점 등) |
| 결론 | 어떤 상황엔 A, 어떤 상황엔 B가 나은지 |

- 실제로 경험한 것만 비교하기 — 안 해본 것을 추측으로 비교하지 않기

## 이미지/영상 배치 (권장 4~6장)
```
[[SLOT: 이미지 | 개수=4 | 역할=A경험1,A경험2,B경험1,B경험2 | 사진=1,2,3,4 | 힌트="..."]]
```

## 특징 마크업
- **TABLE이 핵심** — 비교 기준별로 표 정리:
```
[[TABLE: 헤더="항목,A,B" | 행1="가격,...,..." | 행2="만족도,...,..."]]
```

## 발행 전 체크리스트
- [ ] 실제로 둘 다 경험한 내용인가(추측 비교 아님)
- [ ] TABLE로 기준별 비교가 정리됐는가
- [ ] 상황별 결론을 제시했는가
