# 홍보·광고형 — 할인·프로모션형

> 할인·이벤트 프로모션을 안내하는 글. 기간이 정해져 있어 "지금 신청해야 하는 이유"가 중요해요.

## 글 구조
| 구간 | 내용 |
|---|---|
| 서론 | 프로모션 핵심(무엇을, 얼마나, 언제까지)을 두괄식으로 |
| 본론 | 프로모션 상세 조건, 대상, 신청 방법 |
| 결론 | 마감 임박 안내 + CTA 1개 |

- 할인율·기간처럼 숫자 정보는 정확하게, 애매하게 쓰지 않기
- 과장된 표현("마지막 기회!!", "지금 아니면 안 돼요") 남발은 오히려 신뢰를 깎음 — 담백하게 사실 위주로

## 이미지/영상 배치 (권장 2~4장, 영상 0~1)
```
[[SLOT: 이미지 | 개수=2 | 역할=프로모션포스터,수업환경 | 사진=1,2 | 힌트="..."]]
```

## 특징 마크업
- 핵심 조건(할인율, 기간)은 `[[QUOTE: "..."]]`로 강조
- 신청 링크는 `[[LINK: url="..." | 설명="지금 신청하기"]]`로 마지막에 1개만

## 발행 전 체크리스트
- [ ] 할인율·기간이 정확하게 명시됐는가
- [ ] 과장 표현 없이 사실 위주로 썼는가
- [ ] CTA가 1개, 마지막에만 있는가
